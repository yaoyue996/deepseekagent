DeepSeekAgent

一个兼容 DeepSeek 全模型、支持自定义服务商与自定义模型的安卓 AI 智能体，带来深度思考、工具调用与多模态理解的一站式体验。

GitHub 下载 APK

核心特性

为 DeepSeek 大模型量身打造的原生安卓客户端与智能体。

🧠

DeepSeek 全模型

兼容官方 API，内置 deepseek-v4-pro、deepseek-v4-flash、deepseek-v4-flash-vision-exp。

🔌

自定义服务商

任意 OpenAI 兼容接口的 Base URL + API Key + 自定义模型，一键测试连通性。

🤖

智能体（Agent）

深度思考（reasoning）、工具调用与多轮自动推理，实时展示调用过程。

🧰

内置工具集

时间、计算器、网页抓取、设备信息、文件读写，联网搜索可一键开关。

🖼️

多模态视觉

支持上传图片，视觉模型识别图像内容并作答。

📁

自定义工作区

通过系统文件夹选择器自由指定 agent 读写文件的目录。

💬

流式对话

实时流式输出，支持 Markdown 渲染、代码块、思考过程折叠。

🎨

现代 UI

毛玻璃悬浮卡片、开屏动画、深浅主题切换，贴近 DeepSeek 官方客户端。

🧩

插件生态

开放插件开发 API，jar 插件可扩展 Agent 工具，支持应用内导入。

更新日志

每一次迭代都记录在案。

v2.4.0最新
  • 开放插件开发 API：开发者可用 jar 插件为 Agent 扩展自定义工具。
  • 新增插件目录 /storage/emulated/0/DSA/Plugins，安装 APK 自动生成。
  • 新增「导入插件」功能：应用内选择 jar 文件，自动复制到插件目录并加载。
  • 提供插件开发指南 README.md。
v2.3.02026-08-23
  • 新增开屏动画：DeepSeekAgent 字样逐字浮现 + 呼吸光晕 + 进度条，带平滑过渡进入主界面。
v2.2.02026-08-23
